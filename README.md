# Portofolio – Muhamad Qidamal Fahrizi

Struktur:
- `index.html` – halaman utama
- `css/style.css` – styling
- `js/script.js` – interaksi
- `assets/foto.jpg` – foto profil

## Cara membuka
**VS Code**: `File > Open Folder…` pilih folder ini, install ekstensi *Live Server*, klik **Go Live**.
**Antigravity**: `File > Open Folder…` pilih folder ini. Untuk preview jalankan di terminal `python -m http.server 5500` (atau `npx serve`), lalu buka http://localhost:5500.
